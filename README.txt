CLANKER CAT WEBSITE

Files:
- index.html: main website
- style.css: responsive styling
- assets/clanker-cat-banner.png: generated Clanker Cat banner

HOW TO USE:
1. Upload the contents of this folder to Netlify, or drag the ZIP into Netlify Drop.
2. Before publishing, replace the # links for X and Telegram in index.html with your official profile links.
3. Replace “Coming soon” with the official contract address when it is ready.

This is a static website. No build step is required.
